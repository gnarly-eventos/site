# Gnarly Eventos · Página inicial

Página de gnarlyeventos.com.br: logo da Gnarly e um ingresso para cada festa (A Night To Remember, Nostalgias 2000, Festa do Michael, Lovatic). Cada ingresso mostra a próxima data e quantas datas estão à venda, lidas do `eventos.json` que o robô de cada página de festa já publica. Se a leitura falhar, o ingresso aparece só com o logo.

Para incluir ou tirar uma festa, edite a lista de ingressos no `index.html`.
