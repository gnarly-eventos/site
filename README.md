# Gnarly Eventos · Página inicial

Página de gnarlyeventos.com.br: logo da Gnarly e um ingresso para cada festa (A Night To Remember, Nostalgias 2000, Festa do Michael, Lovatic). As datas e os ingressos ficam nas páginas de cada festa; esta página só leva até elas.

Para incluir ou tirar uma festa, edite a lista de ingressos no `index.html`.
